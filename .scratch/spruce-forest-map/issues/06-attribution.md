# Attribution & license compliance

Type: task
Status: resolved

## Question

Settle the exact attribution the app must display to satisfy **CC-BY 4.0** for the Forest Register data (and the Maa-amet basemap terms): the precise credit text, where it appears (map corner, about screen, stand-detail sheet), and any licence link. Nothing to design — just fix the required wording and placement so the spec can state it verbatim.

## Answer

Required credit, shown in a persistent, expandable map-corner control and repeated in full in the About sheet:

> **Andmed:** Metsaregister, Keskkonnaagentuur (CC BY 4.0) · **Aluskaart:** Eesti põhikaart, Maa- ja Ruumiamet

The CC BY 4.0 licence link is shown in the About sheet. (Maa-amet terms require the basemap's data name + year; use "Eesti põhikaart, Maa- ja Ruumiamet".)
