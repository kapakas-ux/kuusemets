# Spruce Forest Map

A map app that helps Estonian mushroom pickers find **Lactarius deterrimus** by showing where Estonia's spruce stands are.

## Language

**Lactarius deterrimus** (kuuseriisikas):
The milkcap this app is for. It fruits only with spruce, so spruce stands define its habitat.
_Avoid_: riisikas (generic), saffron milkcap (that is *L. deliciosus*, a pine associate)

**Spruce** (kuusk, *Picea abies*):
The conifer that is *Lactarius deterrimus*'s obligate mycorrhizal host.

**Forest stand** (eraldis):
A forest management unit — a polygon with a dominant tree species and a species composition.

**Spruce stand** (kuusemets):
A forest stand whose dominant tree species is spruce. The map's subject — the habitat where *Lactarius deterrimus* is found.
_Avoid_: "any stand that contains spruce" — spruces are a minor component in most Estonian forests, so that definition maps ~65% of the country.

**Other-forest layer**:
Optional non-spruce stands mapped to help find mushrooms other than *Lactarius deterrimus*. Outside the target species' habitat.
